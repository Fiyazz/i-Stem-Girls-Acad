# FACILITATOR TIPS

## <u>FACILITATOR TIPS</u>

Encourage creativity. Emphasize that sketches don’t have to be perfect — focus on clear ideas and storytelling. Move slowly. Walk around to help students troubleshoot file saving and browser preview issues. Introduce fun challenges, like 'Most Colorful Page' to boost creativity. Encourage positive feedback — focus on 'what worked well' before 'what to improve.' Keep the mood light — cheer when their shapes work! Encourage those struggling by pairing them with faster learners. Host a 'Mini Art Gallery' at the end — display everyone’s screens and celebrate creativity. Help them rehearse introductions — confidence and clarity matter more than perfection. Make the day celebratory! Take photos, record clips, and highlight growth. End with encouragement for future TECH learning.

# Month 1 Learning Content

**Month 1 Learning Content — Intro to Tech | Duration: 4 Weeks | 2 Sessions per Week** **| 1hr30m–2hrs per session**

### <u>WEEK 1: ORIENTATION & MICROSOFT WORD (PERSONAL BIO PROJECT)</u>

### DAY 1 — Orientation & Introduction to Word

### Learning Objectives:

- Understand the goals of the program and get familiar with basic digital tools.
- Learn how to open, save, and format text in Microsoft Word.
- Build confidence in expressing personal identity through writing. **Lesson Breakdown:**
1. Welcome & Orientation (15 mins) — Introduce program purpose, schedule, and icebreaker game (‘My Favorite Tech’).
2. Introduction to MS Word (20 mins) — Open Word, explore menu tabs, explain Save/Save As.
3. Task 1: Create Personal Bio Document (60 mins) — Add heading (Name), short paragraph (background, hobbies, skills), insert image, create a 2-column table (Skill | Proficiency).
4. Recap & Sharing (10 mins) — Students read their bios aloud. **Tools/Resources: Microsoft Word, projector, sample bio template, flash drives.** **Expected Outcome: Each student creates and saves their personal bio document professionally formatted.**
### DAY 2 — Collaborative Editing

### Learning Objectives:

- Learn how to edit and collaborate on Word documents.
- Practice giving and receiving constructive feedback.

### Lesson Breakdown:

1. Warm-up (10 mins) — Discussion: Why teamwork matters in tech.
2. Intro to Track Changes & Comments (20 mins) — Demonstrate editing tools.
3. Task 2: Peer Editing (60 mins) — Swap bios with classmates, use Track Changes to correct grammar, add one positive comment and one suggestion.
4. Review (10 mins) — Reflect on collaboration. **Expected Outcome: Students can edit shared documents and communicate feedback clearly.**
### <u>WEEK 2: EXCEL FOUNDATIONS</u>

### DAY 1 — Budget Spreadsheet + Visualization

### Learning Objectives:

- Learn spreadsheet basics (rows, columns, formulas).
- Understand how to calculate totals and visualize data. **Lesson Breakdown:**
1. Introduction to Excel (15 mins) — Interface, data entry, formatting cells.
2. Task 1: Budget Spreadsheet (45 mins) — Create income and expense tables, use =SUM() to calculate totals.
3. Task 2: Visualization (30 mins) — Highlight data, insert chart (Pie/Bar), apply colors and labels.
4. Review (10 mins) — What insights do we get from charts? **Expected Outcome: Each student creates a simple budget sheet and chart.**

### DAY 2 — Data Analysis

### Learning Objectives:

- Use Excel formulas for data comparison.
- Identify patterns in data using functions. **Lesson Breakdown:**
1. Recap (10 mins) — Review SUM & charts.
2. Task 3: Data Analysis (70 mins) — Enter pre-filled data (temperatures, grades, etc.), use =MIN() and =MAX() to find trends, discuss results.
3. Reflection (10 mins) — How does data help decision-making? **Expected Outcome: Students gain functional understanding of data analysis in Excel.**
### <u>WEEK 3: POWERPOINT & STORYTELLING</u>

### DAY 1 — Exploring Tech & Storytelling

### Learning Objectives:

- Understand basic tech terms (Coding, Product Management, Design).
- Learn how storytelling connects with presenting ideas. **Lesson Breakdown:**
1. Discussion (15 mins) — What is tech? What makes your favorite app work?
2. Task 1 (45 mins) — Map out your favorite app — key features, what makes it fun.
3. Group Activity (30 mins) — Present app map to peers.
4. Recap (10 mins). **Expected Outcome: Students learn the role of creativity in product design.**

### DAY 2 — Creating a Presentation

### Learning Objectives:

- Build and design slides with text and media.
- Learn structure and flow in presenting information. **Lesson Breakdown:**
1. Intro (10 mins) — Layout of PowerPoint interface.
2. Task 2 (60 mins) — Create 5-slide presentation: Title, 3 Content, 1 Summary; insert images, transitions, and animations.
3. Task 3 (20 mins) — Plan a Class Event — use slides to propose your idea.
4. Wrap-up (10 mins). **Expected Outcome: Students confidently present with visually appealing slides.**
### <u>WEEK 4: SPECIAL — HACKATHON WEEK</u>

### DAY 1 — Enhance Presentation

### Learning Objectives:

- Learn peer-review and feedback on presentations.
- Add finishing touches to projects. **Lesson Breakdown:**
1. Review (10 mins) — Discuss presentation best practices.
2. Task (60 mins) — Students edit slides with animations/transitions.
3. Peer Feedback (20 mins) — Exchange and review slides in pairs.
4. Reflection (10 mins). **Expected Outcome: Students improve presentation skills and design confidence.**

### DAY 2 (Special) — Tech Careers & Creativity Hackathon

### Learning Objectives:

- Encourage teamwork and problem-solving.
- Introduce creative thinking and pitching ideas. **Lesson Breakdown:**
1. Icebreaker (10 mins) — If you could invent one app...
2. Hackathon Challenge (70 mins) — Teams brainstorm school/life problems and create a 3-slide idea pitch in PowerPoint.
3. Presentations & Feedback (30 mins).
4. Mentor Closing (10 mins). **Expected Outcome: Students develop confidence, creativity, and teamwork while applying learned skills.**

# Month 2 Learning Content

**MONTH 2 LEARNING CONTENT — INTRO TO CODING & DESIGN THINKING** Duration: 4 Weeks | 2 Sessions per Week | 1hr30m–2hrs per session

### <u>WEEK 1: BEGINNER CODING + DESIGN THINKING</u>

### DAY 1 — Service Design & Copywriting

**Learning Objectives:**

- Understand what service design and copywriting mean in product development.
- Learn to think about how technology improves everyday life.
- Build teamwork and brainstorming skills through design exercises. **Lesson Breakdown:**
1. Warm-Up (10 mins) — Discuss examples of favorite delivery apps and how they work behind the scenes.
2. Tech Terms (15 mins) — Introduce Service Design and Copywriting; explain how user experience and clear communication shape tech products.
3. Task 1: Food Delivery App Example (45 mins) — Map out a customer journey for ordering food, then write a short tagline for the app.
4. Activity (20 mins) — STEM Around the World: Learn about female tech leaders and discuss their impact. **Tools/Resources: Whiteboard, markers, printed customer journey template, internet access for research.**
### Expected Outcome: Students understand the connection between design, communication, and user needs.

### DAY 2 — Future Visioning & Innovation

**Learning Objectives:**

- Learn creative problem-solving using real-world examples.
- Begin planning for a long-term team project.
- Practice collaboration and pitching ideas. **Lesson Breakdown:**

1. Future Visioning (20 mins) — Imagine and discuss what technology will look like in 2030.
2. Innovation Workshop (40 mins) — Brainstorm school or community challenges that could be solved with tech tools.
3. Project Planning (25 mins) — Each team selects one idea to develop for the final week’s hackathon.
4. Wrap-Up (10 mins) — Share one takeaway from today’s discussion. **Expected Outcome: Students gain creative confidence and team planning experience.**
### <u>WEEK 2: BEGINNER CODING WITH SCRATCH</u>

### DAY 1 — Intro to Coding

**Learning Objectives:**

- Understand what coding is and how it powers technology.
- Learn to create interactive animations using block-based coding in Scratch. **Lesson Breakdown:**
1. Introduction to Scratch (20 mins) — Explain coding blocks and interface.
2. Task 1: Simple Animation (60 mins) — Build a short story or animation, e.g., 'A Day in My Life.'
3. Reflection (10 mins) — Share what each student created and learned. **Tools/Resources: Laptops with Scratch installed or access to Scratch online, sample project demo.**
### Expected Outcome: Students can build a simple animation using Scratch and describe how coding works.

### DAY 2 — Creative Coding & User Research

**Learning Objectives:**

- Understand how to add sound, motion, and interactivity in Scratch.
- Learn to collect and apply user feedback to improve digital ideas.

**Lesson Breakdown:**

1. Coding Exercise (45 mins) — Enhance animations by adding sound and motion effects.
2. Tech Term (15 mins) — Introduce User Research; explain why knowing users helps make better apps.
3. Activity (30 mins) — Interview a classmate: 'What would make studying easier?' and share findings. **Expected Outcome: Students understand creative coding and basic research methods for designing user-centered apps.**
### <u>WEEK 3: VISUAL DESIGN + CREATIVITY</u>

### DAY 1 — Intro to Design Basics

**Learning Objectives:**

- Learn the importance of color, font, and layout in visual design.
- Apply creativity in redesigning real-life materials. **Lesson Breakdown:**
1. Intro (15 mins) — What makes good design? Explore examples of posters and apps.
2. Exercise (60 mins) — Redesign your school timetable using Canva; make it fun and easy to read.
3. Reflection (10 mins) — Students share how their designs make learning more exciting. **Tools/Resources: Canva, projector, design samples.** **Expected Outcome: Students apply design thinking to improve everyday visuals.**
### DAY 2 — Digital Storytelling

**Learning Objectives:**

- Learn to combine visuals, words, and sound to tell compelling stories.
- Understand the concept of UI/UX Design.

**Lesson Breakdown:**

1. Discussion (15 mins) — How do videos and posters tell stories online?
2. Task (60 mins) — Create a mini digital poster in Canva about your dream tech career.
3. Bonus (15 mins) — Tech Term: What is UI/UX Design? Discuss examples of great user experiences. **Expected Outcome: Students gain digital storytelling skills and understand the basics of user experience design.**
### <u>WEEK 4: MINI HACKATHON + PEER SHOWCASE</u>

### DAY 1 — Hackathon Preparation

**Learning Objectives:**

- Learn how to organize and present group projects.
- Apply teamwork and feedback in improving ideas. **Lesson Breakdown:**
1. Prep Session (20 mins) — Review hackathon expectations and scoring categories (creativity, clarity, teamwork).
2. Team Work (60 mins) — Teams finalize their project ideas and build slides or Scratch projects.
3. Mentorship (20 mins) — Get feedback from facilitators on how to improve projects. **Expected Outcome: Students finalize projects for presentation and practice teamwork.**
### DAY 2 (Special) — Hackathon Day: 'My School, My Tech'

**Learning Objectives:**

- Apply creativity and problem-solving to real-world issues.
- Present and pitch ideas clearly and confidently. **Lesson Breakdown:**

1. Opening (10 mins) — Welcome and quick review of rules.
2. Project Showcase (70 mins) — Teams present their projects that solve school-related challenges using Word, Excel, PowerPoint, or Scratch.
3. Peer Voting (20 mins) — Students vote for their favorite ideas.
4. Awards & Reflection (20 mins) — Mini certificates for 'Best Idea,' 'Most Creative,' and 'Best Teamwork.' **Expected Outcome: Students experience a real hackathon environment and gain presentation confidence.**

# Month 3 Learning Content

### <u>MONTH 3 LEARNING CONTENT — CREATIVITY, INNOVATION & CODING</u>

Duration: 4 Weeks | 2 Sessions per Week | 1hr30m–2hrs per session

### <u>WEEK 1: PRODUCT THINKING & INTRO TO WEB (HTML BASICS)</u>

### DAY 1 — Product Thinking & Paper Prototyping

**Learning Objectives:**

- Understand what Product Management and UI/UX Design mean.
- Learn how to think about user problems and sketch solutions.
- Build teamwork and communication skills through creative exercises. **Lesson Breakdown:**
1. Introduction (15 mins) — Discuss favorite websites and apps. What problems do they solve?
2. Tech Term (15 mins) — Product Thinking: How good apps start from real-life problems.
3. Task 1 (45 mins) — Paper Prototype: Students sketch their own personal website (Homepage, About, Contact).
4. Reflection (15 mins) — Share designs in small groups and explain ideas. **Tools/Resources: Paper, pencils, colored markers, sample wireframe template.** **Expected Outcome: Students can visualize and communicate a simple website idea.**
### DAY 2 — Introduction to HTML

**Learning Objectives:**

- Learn what HTML is and how it structures websites.
- Understand basic HTML tags and how to build a simple webpage. **Lesson Breakdown:**
1. Intro to HTML (20 mins) — Explain <html>, <head>, <body> structure.
2. Demo (20 mins) — Show how to open a file in Notepad and save it as .html.

3. Task 1 (50 mins) — Build your first webpage: Title, header (<h1>), paragraph (<p>), and image (<img>).
4. Review (10 mins) — Open and test pages in the browser. **Tools/Resources: Laptops, Notepad, sample HTML files, browser.** **Expected Outcome: Students create and open their first HTML webpage successfully.**
### <u>WEEK 2: WEB DESIGN CONTINUED + CREATIVITY IN CODE</u>

### DAY 1 — Styling with Colors and Layouts

**Learning Objectives:**

- Learn to use basic HTML elements (lists, links).
- Understand how colors and layout improve design readability. **Lesson Breakdown:**
1. Review (10 mins) — Recap HTML tags learned last week.
2. Task 1 (30 mins) — Create lists of hobbies or favorite things using <ul> and <li>.
3. Task 2 (40 mins) — Add color and style using inline CSS (e.g., <body style='background-color:lightblue;'>).
4. Reflection (10 mins) — How does design make content easier to understand? **Tools/Resources: HTML templates, projector, color palette handout.** **Expected Outcome: Students add color and structure to their first web pages.**
### DAY 2 — Collaboration & Website Review

**Learning Objectives:**

- Learn how to review and improve peers’ work.
- Understand what Frontend Development means. **Lesson Breakdown:**

1. Group Activity (20 mins) — Students pair up and exchange HTML files for review.
2. Tech Term (15 mins) — Frontend Development explained: what users see and interact with.
3. Task (40 mins) — Make improvements based on peer feedback (add new content or style).
4. Recap (15 mins) — Group reflection: 'What did I learn from my partner’s website?' **Tools/Resources: Laptops, USBs, sample site checklist.** **Expected Outcome: Students improve their first websites using feedback and creativity.**
### <u>WEEK 3: PYTHON TURTLE — CODING THROUGH ART</u>

### DAY 1 — Drawing with Code

**Learning Objectives:**

- Understand what Python is and how code can create art.
- Learn how to use Python Turtle to draw shapes and lines. **Lesson Breakdown:**
1. Intro (15 mins) — Explain Python basics: commands, indentation, and what Turtle does.
2. Demo (15 mins) — Show how to open Python IDE and write first command (import turtle).
3. Task (50 mins) — Students draw simple shapes (square, triangle, or star).
4. Wrap-Up (10 mins) — Discuss what each shape required (loops, angles). **Tools/Resources: Python installed laptops, sample code snippets.** **Expected Outcome: Students understand coding logic through creative visuals.**
### DAY 2 — Creative Coding Challenge

**Learning Objectives:**

- Learn to use loops and colors in Python Turtle.
- Apply problem-solving and creativity to code art.

**Lesson Breakdown:**

1. Recap (10 mins) — Quick review of drawing commands.
2. Task (60 mins) — Create a colorful geometric pattern using loops (for i in range...).
3. Tech Term (10 mins) — Algorithm: step-by-step coding instructions.
4. Reflection (10 mins) — What did you learn about patterns and repetition? **Tools/Resources: Python IDE, projector for demo.** **Expected Outcome: Students create original art pieces with Python Turtle.**
### <u>WEEK 4: DEMO WEEK — CREATIVITY & PRESENTATION</u>

### DAY 1 — Project Refinement & Practice

**Learning Objectives:**

- Learn to refine and explain their tech projects.
- Practice teamwork and presentation skills. **Lesson Breakdown:**
1. Review (15 mins) — Recap key lessons from HTML and Python Turtle.
2. Task (60 mins) — Students polish their projects and prepare short presentations.
3. Peer Review (15 mins) — Teams test and provide feedback. **Tools/Resources: Laptops, projector, feedback checklist.** **Expected Outcome: Students refine projects and gain presentation readiness.**
### DAY 2 — Final Demo & Celebration

**Learning Objectives:**

- Present and explain their projects clearly to an audience.
- Celebrate teamwork and progress made over three months.

**Lesson Breakdown:**

1. Opening (10 mins) — Welcome mentors, teachers, and parents.
2. Project Showcase (60 mins) — Each team presents an HTML or Python Turtle project (3–5 minutes each).
3. Awards (20 mins) — 'Best Designer,' 'Best Coder,' 'Best Team Spirit.'
4. Closing (10 mins) — Reflection: 'What I learned in 3 months of STEM.' **Tools/Resources: Certificates, projector, sound system for music.** **Expected Outcome: Students proudly demonstrate their projects and teamwork.**
